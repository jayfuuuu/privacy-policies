FinSight – 智慧理財追蹤

使用 FinSight 遇到問題嗎？關於資產、記帳、市價更新、家人共用帳本或支持者訂閱，都歡迎與我們聯絡。

常見問題

  • 市價沒有更新？到「資產」頁下拉即可手動更新全部市價與匯率；App 開著時每小時也會自動更新。離線時會顯示上次的價格。
  • 我的資料存在哪裡？資料只存在你的裝置與你自己的 iCloud（CloudKit），開發者無法存取。請在 iPhone「設定 → Apple 帳號 → iCloud」確認已登入並允許 FinSight 使用 iCloud，換新手機時資料才能同步。
  • 如何和家人共用帳本？在帳本選單建立家庭帳本後點「邀請」，透過訊息或郵件傳送邀請連結；對方需使用自己的 iCloud 帳號接受邀請。
  • 支持者訂閱不見了？到「設定 → 支援 → 支持開發者」點「恢復購買」。訂閱綁定 Apple 帳號，同一個 Apple 帳號可隨時恢復。
  • 如何取消或管理訂閱？在「支持開發者」頁點「管理訂閱」，或到 iPhone「設定 → Apple 帳號 → 訂閱項目」。取消後不再續訂，本期結束前仍是支持者。
  • 如何加入桌面小工具？長按主畫面空白處，點左上角「編輯 → 加入小工具」，搜尋 FinSight 後選擇尺寸。

聯絡我們
